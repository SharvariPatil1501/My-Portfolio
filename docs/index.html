About Me

I'm a Master's student in Computer Science at the University of Southern California, with a focus on software engineering, data engineering, and applied machine learning. My professional and academic work centers on building systems that hold up under real use — from the query behind a dashboard to the model behind a decision. I enjoy working at the intersection of backend engineering and ML: optimizing the systems data runs through, and building models that turn that data into something usable.

I have hands-on experience with SQL optimization, data modeling, ETL pipelines, and deep learning, and I'm especially interested in how these come together to build reliable, production-grade software — from enterprise dashboards to applications people use directly. I'm always open to software engineering opportunities, collaborations, and conversations about building systems that work at scale.

Real-Time Streaming Data Pipeline

Kafka · Spark Structured Streaming · Airflow · AWS

End-to-end pipeline ingesting simulated e-commerce clickstream events through Kafka, processed with windowed aggregation and watermarking in Spark, then validated and loaded via Airflow into a star-schema warehouse in PostgreSQL — with automated data-quality checks and the full stack containerized in Docker Compose.

Project image

Cotton Leaf Disease Detection

CNN · Deep Learning · Published

Collected, labeled, and augmented a multi-source cotton leaf image dataset, then trained a CNN that reached ~90% accuracy with stable validation loss. Built into an end-to-end app that detects disease from a leaf photo and delivers recommendations through a FarmKart module.

COVID-19 Vaccine Tracker

Kotlin · Android · REST APIs

Android app showing real-time vaccine slot availability by pincode. Fetches live API data, filters by the pincode a user enters, and displays results across clear input and result screens.
