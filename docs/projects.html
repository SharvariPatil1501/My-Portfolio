CNN · Deep Learning · Published

Collected, labeled, and augmented a multi-source cotton leaf image dataset, then trained a CNN that reached ~90% accuracy with stable validation loss. Built into an end-to-end app that detects disease from a leaf photo and delivers recommendations through a FarmKart module.

Kotlin · Android · REST APIs

Android app showing real-time vaccine slot availability by pincode. Fetches live API data, filters by the pincode a user enters, and displays results across clear input and result screens; used Postman to validate API responses during development.

Triangle Detection in Graphs

Graph Theory · Algorithms · ICPC Problem

Solved an ICPC problem of counting triangles in a node-and-link figure by traversing the graph from each node as an apex, then repeating on the figure flipped upside down to catch downward-pointing triangles — summing both counts for the total.
